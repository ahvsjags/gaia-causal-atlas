# GAIA–Causal Research Atlas

An interactive research demonstration using archived display summaries. The study examines climate extremes, ecological memory, and historical fire-risk differences.

- **Full tour:** `?tour=full`
- **Fire-model demonstration:** `?tour=fire`
- **Offline:** open `index.html` in a browser. The site is self-contained; it does not train models or query any external research system.

The 27-step guided tour moves through coverage, imagery, soil-water predictions, and the fire-risk comparisons. The gallery and model lab can also be explored independently. The product credits are in the page footer and `data/provenance.json`. This is not a live fire forecast.
